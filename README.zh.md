## 功能

- **多平台支持**：YouTube、Instagram、TikTok、哔哩哔哩及 yt-dlp 支持的 1000+ 网站
- **格式灵活**：导出 MP4、MKV、MP3、M4A
- **画质可选**：支持选择视频分辨率和音频码率
- **并发下载**：可设置同时下载任务数（1 / 2 / 3 / 5）
- **Cookie 支持**：自动读取 Safari、Chrome 等浏览器 Cookie，下载需登录内容
- **防睡眠**：下载期间可保持系统唤醒
- **自动更新检测**：内置版本检查

## 系统要求

- macOS 12.4 或更高版本
- Apple Silicon（M1 及以上）
